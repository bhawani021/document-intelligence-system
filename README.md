
# Document Intelligence System

An AI-powered local application for document processing,
summarization, information extraction, semantic search,
and intelligent question answering.

## Technology Stack

- Python 3.13
- FastAPI
- Streamlit
- Ollama
- SQLite
- ChromaDB
- Sentence Transformers

## Development Environment

- macOS
- Apple Silicon
- Python 3.13
- uv

## Setup

```bash
uv sync --group dev
```

## Run Tests

```bash
uv run pytest
```
